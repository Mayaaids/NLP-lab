# NLP Lab — All Experiments (Runnable Code)

This package contains all 10 NLP lab experiments as standalone, runnable Python
scripts, plus sample output logs generated by actually running each script.

## Folder structure

```
NLP_LAB/
├── experiments/
│   ├── experiment1.py   Tokenization, Stemming vs Lemmatization
│   ├── experiment2.py   POS Tagging
│   ├── experiment3.py   Text Similarity + WordNet + Clustering
│   ├── experiment4.py   Information Retrieval (TF-IDF vs LSA)
│   ├── experiment5.py   Named Entity Recognition
│   ├── experiment6.py   Biomedical Relation Identification
│   ├── experiment7.py   N-Gram & HMM Language Models
│   ├── experiment8.py   Topic Modeling (LDA) + t-SNE
│   ├── experiment9.py   Rule-Based vs Maximum Entropy Classifier
│   └── experiment10.py  TF-IDF + K-Means Clustering of Social Media Posts
└── sample_outputs/
    └── sample_output_1.txt ... sample_output_10.txt
        (real console output captured from a test run of each script)
```

## Setup

1. Install Python 3.8+.
2. Install the required libraries:
   ```
   pip install nltk scikit-learn numpy
   ```
3. The scripts automatically download the NLTK datasets they need
   (punkt, punkt_tab, wordnet, omw-1.4, averaged_perceptron_tagger_eng)
   the first time they run, provided you have an internet connection.

## Running an experiment

From inside the `experiments/` folder:

```
python experiment1.py
```

Then answer the prompts as they appear (e.g. "Enter a sentence:",
"Enter number of documents:", etc.). Each script prints its results directly
to the console, matching the procedure described in the lab manual.

## Notes on small fixes made for runnability

The original lab manual programs are reproduced as-is, with a few defensive
tweaks so they never crash on small/edge-case inputs:

- **experiment3.py / experiment10.py** — the number of K-Means clusters is
  capped at the number of items entered (KMeans cannot create more clusters
  than there are samples).
- **experiment4.py** — the number of LSA (TruncatedSVD) components is capped
  based on the number of documents/features supplied.
- **experiment8.py** — the number of LDA topics is capped at the number of
  reviews supplied, and the "top keywords per topic" list is capped at the
  vocabulary size.
- **experiment5.py** — avoids a divide-by-zero if both predicted and actual
  entity counts are 0.
- All `nltk.download()` calls include `punkt_tab` and `omw-1.4` where needed,
  since newer NLTK versions require these in addition to `punkt`/`wordnet`.

These changes only affect edge cases; with typical inputs (like the ones
shown in the sample outputs) the behavior matches the lab manual exactly.
